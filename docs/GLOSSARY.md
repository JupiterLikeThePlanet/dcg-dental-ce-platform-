# Glossary

| Term | Meaning |
|---|---|
| CE | Continuing education. Dentists need a set number of credit hours to keep their license. |
| CE credits | Hours of credit a class is worth. Stored in `ce_credits`. |
| AGD | Academy of General Dentistry. Its subject areas are the categories we use. |
| Provider | Whoever runs the class and submits the listing |
| Listing | One class on the site |
| Submission | A listing before or during review. Lives in `submissions`. |
| Class | An approved, live listing. Lives in `classes`. |
| Attendance type | on-site, hybrid, remote, or pre-recorded |
| Admin post | A class the admin created directly (`is_admin_post`) |
